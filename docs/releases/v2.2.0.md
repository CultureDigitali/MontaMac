# MontaMac 2.2.0

Reliability and operations release created by Luigi Strazzullo for Culture Digitali Srl.

## Highlights

- Automatic recovery for interrupted mounts, with bounded retries and health checks.
- New sidebar sections for live transfers, cache management, and recent problems.
- Accurate rclone JSON telemetry: current speed, progress, ETA, active files, and session totals.
- Global and per-profile cache limits, reserved free space, and safe cleanup for inactive drives.
- Localized issue history and privacy-redacted diagnostic exports.
- Sparkle update support with HTTPS feed validation and EdDSA signatures.
- Automated Developer ID signing, Apple notarization, stapling, checksums, and appcast publishing.

## Compatibility

Existing 2.1 profiles remain compatible. The optional cache limit is absent on old profiles and safely falls back to the new 5 GB default. Credentials remain in Keychain.

## Download verification

```bash
shasum -a 256 -c MontaMac-2.2.0.pkg.sha256
```

Only the GitHub release workflow can produce the official notarized package. Local builds are ad-hoc signed when Apple credentials are unavailable.

## Rollback

You can reinstall 2.1.1 without deleting profiles or Keychain entries. Unmount active drives first. The extra 2.2 cache-limit field is ignored safely by the previous release.
