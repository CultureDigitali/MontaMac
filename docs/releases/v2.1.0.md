# MontaMac 2.1.0

First public release of MontaMac, created by Luigi Strazzullo for Culture Digitali Srl.

## Highlights

- Mount FTP, SFTP and WebDAV drives in Finder.
- Reusable profiles, groups, favorites and search.
- Keychain password storage and private local files.
- Dashboard, statistics, diagnostics and activity logs.
- Complete Italian, English, French and Spanish interface.
- Automatic checks for rclone and FUSE-T.

## Download verification

Download both `MontaMac-2.1.0.pkg` and `MontaMac-2.1.0.pkg.sha256`, then run:

```bash
shasum -a 256 -c MontaMac-2.1.0.pkg.sha256
```

## Important installation notice

This package uses a local Hardened Runtime signature but is not notarized with an Apple Developer ID. Gatekeeper may display a warning. Install only after verifying the checksum and the repository source.
