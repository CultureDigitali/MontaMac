# MontaMac 2.1.1

Maintenance release created by Luigi Strazzullo for Culture Digitali Srl.

## Highlights

- Accurate live transferred-byte statistics from rclone.
- Persistent 30-day transfer totals without activity-log spam.
- Local VFS cache disk-usage indicator.
- Adaptive dashboard cards and polished creator credits.
- Automatic dashboard refresh in Italian, English, French and Spanish.

## Download verification

Download both `MontaMac-2.1.1.pkg` and `MontaMac-2.1.1.pkg.sha256`, then run:

```bash
shasum -a 256 -c MontaMac-2.1.1.pkg.sha256
```

## Installation notice

This package uses a local Hardened Runtime signature but is not notarized with an Apple Developer ID. Gatekeeper may display a warning. Install only after verifying the checksum and repository source.
